# Rfrengression: Frugal, Flexible, Faithful Causal Data Simulation via Frengression

Deep generative models for causal data simulation. Learns joint
distributions of covariates, treatments, and outcomes, enabling
interventional sampling via do-calculus. Implements three model classes:
cross-sectional (Frengression), longitudinal (FrengressionSeq), and
survival (FrengressionSurv). Based on "Frugal, Flexible, Faithful:
Causal Data Simulation via Frengression" by Shen and Meinshausen (2025)
[arXiv:2508.01018](https://arxiv.org/abs/2508.01018).
